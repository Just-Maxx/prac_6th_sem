# Метод продолжения по параметру для краевых задач ОДУ

Проект по практикуму: реализация метода продолжения по параметру для решения краевых задач обыкновенных дифференциальных уравнений.

## Идея метода

Рассматривается краевая задача вида

```text
dx/dt = f(t, x),
R(x(a), x(b)) = 0.
```

Она сводится к нелинейному уравнению

```text
Phi(p) = 0,
```

где `p` — параметр задачи Коши.

Для поиска `p` используется метод продолжения по параметру. Внутри программы решаются:

- внутренняя задача Коши для `x(t, p)`;
- уравнение в вариациях для вычисления `Phi'(p)`;
- внешняя задача метода продолжения.

## Текущий статус

На текущем этапе реализованы:

- задание краевой задачи через графический интерфейс;
- ввод правых частей системы ОДУ в виде строк;
- ввод граничных условий в виде строк, например `x1(t0) = 0`;
- разбор выражений через SymPy;
- автоматическое построение якобиана правой части системы;
- автоматическое построение якобианов граничных условий;
- решение внутренней задачи Коши;
- решение уравнения в вариациях;
- вычисление `Phi(p)` и `Phi'(p)`;
- внешний шаг метода продолжения по параметру;
- полноценный решатель краевой задачи;
- вывод найденного параметра, значения `Phi(p)` и нормы ошибки граничных условий;
- построение графиков решения;
- выбор между графиком компонент от времени и фазовой плоскостью.
- верхнее меню приложения;
- сохранение и загрузка пользовательских задач;
- удаление сохранённых пользовательских задач;
- встроенные примеры задач из статьи;
- отдельная папка для встроенных примеров `preset_tasks`;
- отдельная папка для пользовательских задач `user_tasks`;
- отдельная папка для результатов расчётов `results`;
- график сходимости метода;
- справочные окна `Формат ввода`, `О программе`, `Об авторе`.

## Формат ввода

Правые части системы вводятся по одной строке на каждое уравнение.

Например, система

```text
x1' = x2
x2' = -x1
```

вводится так:

```text
x2
-x1
```

Граничные условия можно вводить в обычном виде:

```text
x1(t0) = 0
x1(t1) = 1
```

Для переменных используются обозначения `x1`, `x2`, ..., `xn`.

Доступные функции:

```text
sin, cos, tan, exp, log, sqrt, abs
```

## Сохранение задач

Пользовательские задачи можно сохранять и загружать через меню `Файл`.

Встроенные демонстрационные задачи хранятся в папке `preset_tasks`.

Пользовательские задачи сохраняются в папку `user_tasks`, а результаты расчётов планируется сохранять в папку `results`. Содержимое этих папок не добавляется в Git, кроме файлов `.gitkeep`.

## Структура проекта

- `main.py` — запуск графического интерфейса;
- `src/models.py` — основные структуры данных для задачи и результата решения;
- `src/parser.py` — разбор пользовательских выражений через SymPy;
- `src/inner_solver.py` — решение внутренней задачи Коши;
- `src/variational_solver.py` — решение внутренней задачи вместе с уравнением в вариациях;
- `src/residuals.py` — вычисление `Phi(p)` и нормы ошибки;
- `src/jacobian.py` — вычисление якобиана `Phi'(p)`;
- `src/continuation.py` — внешний шаг метода продолжения по параметру;
- `src/bvp_solver.py` — общий решатель краевой задачи;
- `src/gui.py` — графический интерфейс;
- `src/task_storage.py` — сохранение, загрузка и удаление задач в формате JSON;
- `src/app_texts.py` — тексты справки, описания программы и информации об авторе;
- `preset_tasks/` — встроенные примеры задач;
- `user_tasks/` — локальные пользовательские задачи;
- `results/` — локальные результаты расчётов.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

После запуска откроется графический интерфейс, в котором можно задать систему ОДУ, граничные условия, начальное приближение и параметры расчёта.
