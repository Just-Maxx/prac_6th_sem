# История изменений

## [0.6] - 25-05-2026

### Добавлено
- Добавлена папка `tests` с автоматическими тестами.
- Добавлены тесты для проверки решения тестовой краевой задачи.
- Добавлены тесты для проверки функции `Phi(p)`.
- Добавлен тест сравнения якобиана, вычисленного через уравнение в вариациях, с конечно-разностным якобианом.
- Добавлены тесты для проверки парсера правых частей ОДУ и граничных условий.
- Добавлен тест обработки неизвестной функции в пользовательском вводе.
- Добавлен тест сохранения результатов расчёта.

### Изменено
- В `requirements.txt` добавлена зависимость `pytest`.
- В README добавлен раздел с инструкцией по запуску тестов.

## [0.5] - 18-05-2026

### Добавлено
- Добавлено сохранение результата расчёта в отдельную папку `results`.
- Добавлено сохранение исходной задачи в файл `task.json`.
- Добавлено сохранение найденного решения в файл `solution.json`.
- Добавлено сохранение таблицы решения в файл `solution_table.csv`.
- Добавлено сохранение текстового отчёта в файл `result.txt`.
- Добавлено сохранение текущего графика вместе с результатом в файл `plot.png`.
- Добавлена возможность отдельно сохранять текущий график в PNG или PDF.
- Добавлен табличный просмотр численного решения.
- Добавлены горячие клавиши для основных действий приложения.

### Изменено
- Расширено меню `Файл`.
- Добавлено меню `Вид`.
- Последний результат расчёта теперь сохраняется внутри приложения для просмотра, экспорта и сохранения.

## [0.4] - 05-05-2026

### Добавлено
- Добавлено верхнее меню приложения.
- Добавлены разделы меню `Файл`, `Примеры` и `Справка`.
- Добавлена возможность сохранять пользовательские задачи в JSON.

- Добавлены встроенные примеры задач из статьи.
- Добавлены папки `user_tasks` и `results` для локальных пользовательских данных.
- Добавлен модуль `task_storage.py` для работы с JSON-задачами.
- Добавлен модуль `app_texts.py` для хранения текстов справки и описаний.
- Добавлено окно справки по формату ввода.
- Добавлено окно с информацией о программе.
- Добавлено окно с информацией об авторе.
- Добавлен график сходимости метода.
- Добавлено улучшенное форматирование чисел в пользовательском выводе.

### Изменено
- Улучшена структура проекта для дальнейшего расширения.

## [0.3] - 04-05-2026

### Добавлено
- Добавлен внешний шаг метода продолжения по параметру.
- Добавлен полноценный решатель краевой задачи `solve_bvp_continuation`.
- Добавлен класс `BVPSolution` для хранения результата решения.
- Добавлен парсер правых частей ОДУ через SymPy.
- Добавлен автоматический расчёт якобиана правой части системы.
- Добавлен парсер граничных условий.
- Добавлена поддержка граничных условий в привычном виде, например `x1(t0) = 0`.
- Добавлен графический интерфейс на Tkinter.
- Добавлен ввод параметров задачи через интерфейс.
- Добавлен вывод найденного параметра, значения `Phi(p)`, нормы ошибки и истории сходимости.
- Добавлено построение графика решения в интерфейсе.
- Добавлен выбор типа графика: компоненты от времени или фазовая плоскость.
- Добавлен выбор осей для фазовой плоскости.
- Добавлена обработка неизвестных функций в выражениях пользователя.

### Изменено
- `main.py` теперь запускает графический интерфейс.
- Формат ввода граничных условий стал ближе к обычной математической записи.
- Улучшено форматирование чисел в пользовательском выводе.
- Улучшено расположение элементов интерфейса.
- Обновлены зависимости проекта: добавлена библиотека `sympy`.

## [0.2] - 30-04-2026

### Добавлено
- Добавлено вычисление якобиана правой части системы.
- Добавлено вычисление якобиана граничной невязки.
- Реализовано решение внутренней задачи вместе с уравнением в вариациях.
- Добавлено вычисление якобиана `Phi'(p)` через матрицу вариаций.
- Добавлена проверка якобиана методом конечных разностей.
- Обновлён вывод программы: теперь отображаются невязка, якобиан и разность якобианов.

### Изменено
- Расширен класс `BVPProblem`: добавлены поля `rhs_jacobian` и `boundary_jacobian`.
- Тестовый пример дополнен аналитическими производными.
